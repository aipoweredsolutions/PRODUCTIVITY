About & help

Simple tips to keep your private workspace safe and useful.

Version

Productivity Planner

Back up

Use Back up in the Settings header and keep the downloaded file somewhere safe. Back up regularly, especially before changing devices.

Restore

Choose “Restore JSON” in Data & backups and select a backup file. Restoring replaces the current workspace, so export a fresh backup first.

Install tips

This app works fully offline. Save the file to your device and open it in your browser. Bookmark it for quick access. Your data is stored in this browser, so back up regularly with Back up JSON.
